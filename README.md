# Helpet
 
Plataforma digital para facilitar a adoção de animais e as doações para ONGs de proteção animal. Projeto de pesquisa desenvolvido em HTML, CSS e JavaScript.

## Sobre o projeto

O Helpet nasceu como um projeto de pesquisa com o objetivo de desenvolver uma plataforma digital que torne a adoção de animais e as doações para ONGs mais simples, rápidas e acessíveis. Muitos animais continuam à espera de um lar, e muitas organizações de proteção animal dependem da ajuda de voluntários e doadores, mas nem sempre conseguem divulgar seu trabalho ou alcançar quem gostaria de ajudar. Pensando nisso, o site reúne em um só lugar os pets disponíveis para adoção, as informações de cada um deles e a possibilidade de apoiar as ONGs por meio de doações.

Ao longo do site, o usuário pode criar uma conta, fazer login, explorar o catálogo de animais, conhecer a história e as características de cada pet e escolher como contribuir. A proposta é aproximar quem quer adotar ou ajudar as instituições que cuidam dos animais, incentivando a adoção responsável e fortalecendo o trabalho das ONGs.
